# Future maybes

Parked ideas. None are planned; each says what it would build on.

## Changes what it is

- **Two cats, one page.** Two copies on two browsers chat about the same page in real time, each with its own model and highlights. One defends what the page claims, the other attacks it; you read the debate. Fully local.
- **The page answers back.** Rewrite the page itself instead of answering in the panel: an article as a 5-step checklist, a spec for a beginner, a recipe for two. Same page, transformed, with a toggle back.
- **A walking browser.** Give it a goal ("cheapest flight landing before noon") and walk away. It opens tabs, scans, follows links and builds a table, all locally; you come back to the answer and its path. Builds on the follow-links crawler, table extraction and a planning loop.

## Features

- **Watch a region and ping your phone.** "Tell me when this changes": rescan on a timer, compare the crop and its OCR, push before/after through notify.
- **Browsing memory for Claude Code.** Captures go to a local store exposed as an MCP server, so a coding agent can answer from what you actually read.
- **Visual memory search.** Describe each tile at scan time; search captures by appearance ("the page with the green painting").
- **Comparison tables across pages.** Follow links over N listings, then "compare these" makes one merged table.
- **Scripture links on any page.** Detect verse references, show the text inline from a bundled translation, with cross-references. Offline.
- **Alt text for the whole web.** Describe every image that lacks alt text, over the image; include images in read-aloud.
- **Flashcards from what you read.** Q&A cards from captures on a spaced schedule; each answer links to its source passage.
- **A cat that roams the page.** The mascot walks onto the page, sits on the cited passage, pounces on the region being analysed.
